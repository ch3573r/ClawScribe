# ClawScribe 0.5.47

This Windows GPU release improves meetings recorded with **Record now, transcribe
later**, fixes summaries of very long meetings, and refines exports, project
filtering, and the sidebar. The verified draft build was published unchanged as the
stable release on 2026-09-29 after owner-confirmed real-device acceptance.

## Audio-only meetings and playback

A saved meeting that has audio but no transcript now says **No transcript yet**
and offers **Transcribe now**, instead of showing the home screen's welcome text.
When no audio file is found, the meeting explains that and offers to open the
recording folder. For a first transcript, the dialog says **Transcribe Meeting**
and **Start Transcription** and omits the replace-transcript warning.
**Generate Summary** appears once a transcript exists.

The playback timeline now covers the whole meeting instead of only the transcript
lines loaded so far. Every meeting with saved audio gets a playback bar, including
audio-only meetings and meetings with speaker attribution turned off.

## Long meetings

Since 0.5.40, generating a summary or copying the transcript failed for meetings
with more than 1,000 transcript lines. Both now read the transcript in pages. If a
page cannot be read, the action stops with an error instead of using a partial
transcript. Meeting chat and document exports were not affected.

## Exports

- **Timestamps** now also removes source times and timestamp notes from the
  summary, so a summary can be exported without them. **Speaker labels** applies
  to transcript lines only and is hidden for summary-only exports.
- Markdown tables in the summary export as real tables to Word and OneDrive DOCX,
  OneNote, and Confluence. In Word, tables have a repeating header row and are
  separated by an empty paragraph.
- Word export uses a Word icon in the Export menu.

## Library and navigation

- The Meetings page filters by several project tags at once, matching meetings
  with any or all of them, or shows untagged meetings.
- Sidebar entries show the meeting's date (Today, Yesterday, day and month, or a
  full date for earlier years) instead of "Recent meeting".
- Drag the sidebar's right edge to resize it; double-click the edge to reset.
  The width is remembered, and the edge also responds to the arrow, Home, and End
  keys. Recording controls and status messages stay centred under the content.
- The recording bar's bookmark control is a round icon button that matches Pause
  and Stop.

## Validation and acceptance

Validation passed 227 frontend tests and 628 required native app tests, with three
native exclusions, plus five helper tests. The native suites include DOCX, OneNote,
and Confluence table rendering. Typechecking, Windows GPU compilation, a production
frontend build, and repository safety checks passed. The installer artifacts passed
checksum, build-identity, updater-manifest, and signature verification; the
verification record is attached to the GitHub Release.

The build was installed as an upgrade from 0.5.46 with the existing meeting library
intact. The repository owner then confirmed that it works for the acceptance checks:
microphone and system-audio recording, a clean Stop and a second recording, an
audio-only recording followed by **Transcribe now**, a Word export containing tables,
and sidebar width after a full restart. Detailed device and model measurements were
not recorded. See the [Windows acceptance checklist](../windows-release.md#required-real-device-acceptance).
Automated tests do not establish real-device capture quality or active GPU inference.

## Installation and updates

Installer, runtime, and updater versions are **0.5.47**. This is a stable release:
older installations can discover it without enabling prereleases. The updater
uses the NSIS setup; an MSI is also provided. Finish recording and saving first.

The `windows-gpu` profile uses Whisper Vulkan and ONNX/sherpa DirectML. A supported
GPU driver or official Vulkan runtime remains required. Tauri updater signatures
are separate from Windows Authenticode publisher signing; Windows may still show
an unknown-publisher or SmartScreen warning.
