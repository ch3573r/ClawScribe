# ClawScribe 0.5.42 Preview

This Windows x64 prerelease adapts selected reliability fixes from Meetily
Community Edition 0.4.1: resumable speech-model downloads, correct timing for
HE-AAC imports, stricter handling of model reasoning text in notes, exact
end-of-recording speech boundaries, and a portable CPU baseline for Windows
builds. It is not a wholesale merge of Meetily 0.4.1; ClawScribe keeps its
Windows GPU profile, recording lifecycle, and engine choices. See
[UPSTREAM.md](../../UPSTREAM.md).

## Speech Model Downloads

- Whisper and Parakeet downloads write to a `.partial` file and move it into
  place only after the full HTTP length has arrived. Retry resumes the partial
  file after checking the server's byte range; a server that ignores the range
  restarts only that file.
- Parakeet retry keeps files that are already complete instead of clearing the
  model directory. Cancelling a Whisper download now keeps its partial file for
  the next attempt instead of deleting it.
- Cancellation is per model and waits up to five seconds for the download to
  close its files. If it has not finished, cancel reports that it is still
  pending and the model stays reserved, so a second download cannot write the
  same file.
- A model becomes available only after validation passes. A downloaded Whisper
  file without a valid GGML header is removed.
- Whisper downloads now also stop after 30 seconds without data, and a single
  request is limited to one hour, as Parakeet downloads already were. Retry
  continues from the partial file.

## Imports

HE-AAC files carry a container sample rate that can be twice the rate of the
audio the decoder actually produces. Imports now use the decoded rate, so
duration and timing survive conversion to 16 kHz. Previously the container rate
was used, which could halve the imported duration and distort timestamps.

## Reasoning Text In Notes

- Complete `<think>` and `<thinking>` blocks, including uppercase and attribute
  variants, are removed from model output. Unfinished or stray reasoning tags
  now fail generation with a retry message instead of being saved.
- Codex meeting output and every structured field, including JSON-escaped tags,
  receive the same check.
- Saving an edited summary that contains reasoning tags is rejected. Previously
  saved notes that contain them are hidden with a regeneration message; the
  stored copy is not deleted. Summary sources are transcript evidence and are
  not checked.
- Notes that legitimately quote a literal `<think>` tag are treated the same way.

## Recording End Boundaries

When a recording stops, the voice-activity detector's padded final frame is
trimmed to the real end of the audio, including when a long segment is split
during that flush. Padding no longer adds silence to the last speech segment or
extends its end time beyond the recording.

## Windows CPU Baseline

- Release and native-test builds compile Rust code for `x86-64-v2` and build
  Whisper's CPU code without build-machine tuning or AVX-512. AVX2 stays
  enabled. Earlier Whisper builds used ggml's default host-native tuning for
  the build machine's CPU.
- Bundling and native tests fail if any Whisper build cache was configured with
  host tuning or AVX-512. The release workflow first removes Whisper caches left
  on the build machine from earlier host-tuned builds, so they are rebuilt.
- The Vulkan and DirectML acceleration paths are unchanged.

## Validation

Frontend typechecking, **74 frontend tests** (including 4 new CPU-portability
tests), workspace Rust formatting, the public repository safety scan, and the
workflow policy check passed. The Windows GPU preflight on the designated build
machine passed locked Rust checking and **325 native tests** (0 failed,
2 optional tests ignored). New required suites cover resumable
downloads and cancellation, the HE-AAC decoder fixture, and VAD flush endpoints.

Download tests use a local HTTP test server. An interrupted and resumed download
from Hugging Face inside the installed app was not exercised. HE-AAC handling
was tested with Meetily's synthetic fixture only.

## Installation And Update Behavior

Runtime, installer, and updater versions are **0.5.42**, newer than 0.5.41.
This is a prerelease: enable **Include prereleases** to be offered it, or
download the NSIS setup/MSI manually. The stable channel remains on 0.5.41.

The `windows-gpu` build uses Whisper Vulkan and ONNX/sherpa DirectML. Speech
models, the active `cpal` revision, and the bundled Codex runtime (0.157.0) are
unchanged; Whisper's native CPU build flags changed as described above. A
supported driver or official Vulkan runtime remains a startup prerequisite.

Both installers include detached Tauri updater signatures, SHA-256 checksums,
build identity, and updater metadata. Updater signing is separate from Windows
publisher signing; review the release's Authenticode status. Windows security
policy still applies.

## Remaining Acceptance

Real microphone/system-audio capture, playable saved audio, prompt stop and a
second recording, graphical installation/upgrade, installed-app update discovery,
native UI accessibility/scaling, multilingual recognition and factual summary
quality, and sustained notebook memory/backlog behavior remain unconfirmed. This
preview does not assert capture-smoke confirmation or stable readiness.

Also unconfirmed for this release: a real interrupted and resumed model download,
imports of real HE-AAC recordings, and Whisper CPU performance and startup on
CPUs other than the build machine compared with 0.5.41.
