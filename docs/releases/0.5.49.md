# ClawScribe 0.5.49 Preview

This Windows GPU preview adds memory across saved meetings. It delivers the meeting-memory phase; document attachments and live assistance remain in the follow-up plan.

## Meeting memory

- Search saved transcripts by keyword without downloading an embedding model. Choose selected meetings, project tags (match any or all), untagged meetings, and an inclusive date range, or explicitly choose the whole library.
- Enable optional local semantic search in Knowledge settings. The pinned multilingual E5 model runs on CPU, supports English and German, and keeps embeddings on this device. Recording takes priority over background indexing. Settings expose download, progress, Pause, Retry, and Rebuild controls.
- Ask questions about the selected meetings using the configured summary provider. A configured cloud provider receives the question and bounded meeting context. Conversations are saved locally. Answers show the retrieval mode, provider and model actually used, with request-specific source references. Existing meeting chat history remains readable; expanded scope uses a separate library conversation.
- Preview sources, reveal the canonical transcript line, or seek to its saved audio position. Corrections and deletions invalidate old evidence; stale, missing and restored historical sources are labeled. Short-answer question context is displayed separately from citations emitted by the model.

## Preview acceptance

Feature validation passed typecheck, a production frontend build and 250 frontend tests, with native Windows GPU checks, 92 knowledge tests and seven conversation backup tests. The final installer preflight, native release suite and artifact integrity checks are separate release gates. Published build and verification metadata record their exact results. Installed-app offline search, provider failures, citation clicks, focus and playback remain pending. The exact build also needs microphone plus system-audio playback, clean Stop, a second recording, installer/upgrade and update discovery, and sustained notebook/device/sleep-wake acceptance before stable promotion.

A fixed synthetic acceptance run with the packaged CPU Qwen3.5 4B helper passed all 12 required answer assertions. This certifies that baseline only. Answers can still omit a relevant citation or describe a source imprecisely; inspect the linked evidence. The measured 10,000-meeting retrieval fixture found its expected result for 27 of 30 queries. Background indexing and semantic inference were tested against their resource bounds, with limited memory headroom; installed long-meeting behavior still needs evaluation.

## Installation and updates

The numeric installer, runtime and updater version is 0.5.49. Stable remains 0.5.48. After publication, enable **Include prereleases** to discover this preview or install it manually from this release. Drafts do not appear in the updater. The updater uses the NSIS setup; an MSI is also included. Finish recording and saving before installing.

The Windows GPU profile uses Whisper Vulkan and ONNX/sherpa DirectML. Meeting embeddings and the evaluated local answer helper use CPU. Tauri updater signatures are separate from Windows publisher signing; Windows may show a publisher warning. Verify the published checksums and exact build metadata before installation.
