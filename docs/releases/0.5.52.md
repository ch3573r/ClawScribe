# ClawScribe 0.5.52 preview

This Windows GPU preview applies the UI conventions across ClawScribe so the
changed screens can be checked in light and dark themes. It builds on
[0.5.51](0.5.51.md). Stable remains 0.5.48.

## UI consistency

Shared components, Settings, Home and recording, Meeting details, Onboarding,
and import/backup screens now use shared controls, sentence-case labels and
semantic theme colors. All 68 files in the committed UI conventions baseline
have zero recorded raw palette, hex-color or native-control violations.

Success, warning, error and info colors use the existing theme tokens. Home
status rings and dialog/import overlays use named colors with their original
opacity. Tailwind and PostCSS use one canonical configuration each, retaining
application fonts, sidebar/chart colors, accordion animations and CSS prefixing.

This is an appearance and control consistency update. Application behavior,
screen layout, recording/transcription logic, providers and storage are unchanged.
Meeting memory retains the search, answer coverage and cited conversations from
0.5.51. The separate semantic-search information popover feature remains outside
this cleanup batch.

## Screens to check in light and dark

- Shared navigation and dialogs: expanded/collapsed Sidebar, model/language and
  device controls, recording/transcript status, progress, bookmarks and notices.
- Settings: Add-ons/Diagnostics, Transcription and local model managers, Summary
  models/templates, Recording, Shortcuts and Beta.
- Home and recording: dashboard, pre-record settings, recording controls,
  permissions, recovery and dialog overlays.
- Meeting details: summary, transcript/timeline, chat, corrections, citations,
  transcription/diarization dialogs and export previews.
- Onboarding: permissions, setup progress and model downloads.
- Import and backup: audio import/drop overlay and Backup and restore. Existing
  unmounted legacy import and editor/form components are cleaned up without being
  added to application flows.

For each area, check light/dark themes, the selected accent, keyboard focus,
enabled/disabled/loading/error states and desktop layouts at 1000 px and wider.
These installed checks remain pending for this preview.

## Validation and pending acceptance

Designated-runner typecheck, frontend tests, production build and UI-conventions
checks validate the source changes. Config regressions verify the active TS/MJS
configs, retained fonts/animations/prefixing, semantic utilities, ring colors and
overlay opacity. Windows GPU preflight, native regression suites, installer
build and uploaded-asset integrity are separate publication gates; the published
verification record contains their exact results and ignored checks.

Installed UI/theme/focus checks, microphone plus system-audio capture and saved
playback, clean Stop and a second recording, retained meetings on upgrade, real
meeting-memory answers/retrieval/citations, installed update/signature acceptance,
and sustained notebook/device/sleep-wake recovery remain pending before stable
promotion. This public prerelease is for manual evaluation and does not establish
stable readiness or capture-smoke confirmation.

## Installation and updates

The numeric installer, runtime and updater version is 0.5.52, greater than
0.5.51. After draft staging and asset verification, publish as a prerelease with
latest=false. Stable remains 0.5.48. Enable **Include prereleases** to discover
the published preview or install manually; drafts are excluded from updates.
Finish recording and saving before installation.

The release includes NSIS and MSI installers, detached Tauri updater signatures,
checksums, build metadata and an updater manifest. The Windows GPU profile uses
Whisper Vulkan and ONNX/sherpa DirectML; meeting embeddings use CPU. Tauri updater
signatures are separate from Windows publisher signing. Verify checksums and
build identity before use.
