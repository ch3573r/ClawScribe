# ClawScribe 0.5.55 preview

This Windows GPU preview makes reference attachment easier to find and restores
compact corner chat. It builds on [0.5.54](0.5.54.md). Stable remains 0.5.48.

## Reference attachment and meeting chat

Use **Meetings → Meeting memory → Attach file** beside the Sources controls.
One explicitly selected meeting within the current project/date filters is the
destination. Otherwise choose a saved meeting in the searchable dialog, even
when only one meeting is available. The destination joins the selected sources
after import. Files remain attached to saved meetings; adding a file does not
select its excerpts or enable sharing automatically.

Meeting details chat opens as a compact, non-modal corner popup with collapsed
question-scope controls, a fixed composer and one history scrollbar. Draft
typing reuses unchanged Markdown and citation content. This reduces rendering
work; installed WebView typing latency has not been measured.

**Use selected references for answers** replaces provider-specific consent
wording. The explanation identifies the configured answer provider, which can
be changed in Summary settings. Reference extraction, preview and local search
stay local. Sending selected excerpts to an external provider remains off by
default per conversation. Built-in AI uses references locally.

## Validation, limitations and updates

The feature's designated-runner validation passed typecheck, production build
and 365 frontend tests, including scope-change and cancellation regressions and
history reuse with 120 answers containing 700 evidence entries each. UI debt
remains zero. The release verification record identifies the exact packaged
commit, native validation, assets, checksums and updater manifest.

Extraction limits, provider transport, evidence maps, portable backups and
recording paths are unchanged. Existing live-assistance limitations from
[0.5.54](0.5.54.md) remain: recording-context recovery can overlap at most two
metadata reads, and the sharing control has a label-association issue when its
Home and Settings instances are rendered together.

Exact-build dual-source playback, clean Stop and a second recording, upgrade,
installed update/signature acceptance, provider factual accuracy and comparable
two-hour enabled/disabled live-assistance performance remain pending before
stable promotion. Earlier audio acceptance does not certify this build.

The installer/runtime/updater version is 0.5.55. Stage a draft, verify both
installers, detached Tauri signatures, checksums, build identity and updater
manifest, then publish as a prerelease with latest=false. Stable stays 0.5.48.
Enable **Include prereleases** or install manually; drafts are excluded from
updates. Finish recording and saving before installation. Tauri updater
signatures are separate from Windows publisher signing. The release profile is
windows-gpu: Whisper Vulkan and ONNX/sherpa DirectML; meeting embeddings use CPU.
