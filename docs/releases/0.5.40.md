# ClawScribe 0.5.40 Preview

This Windows x64 prerelease fixes reliability and performance problems found in
transcription, meeting state, summary providers, local inference, persistence,
and Microsoft exports. It builds on the review tools introduced in 0.5.39.

## Transcription And Responsiveness

- Preserve legitimate Whisper repetitions and phrases instead of deleting words
  through phrase blacklists. Short German answers and negation remain intact.
  This removes destructive postprocessing; it is not an acoustic accuracy score.
- Fix Whisper and Parakeet model-switch deadlocks. Construct local speech models
  on blocking workers under the existing native inference permit.
- Pass import/retranscription speech buffers into inference without another PCM
  copy. Cancelling a hosted request exits without starting local fallback.
- Resolve Nemotron Auto consistently from the system locale for live and batch
  transcription. Choose an explicit language when speech differs from that
  locale. Parakeet Auto no longer falsely labels the source language English.

## Meeting State And Saves

- Discard old transcript, source-page, summary, and recording-poll responses after
  navigation or newer lifecycle events. Clean up late listener registrations.
- Load meeting metadata and transcript pages concurrently. Prevent duplicate
  page loads and use indexed, deterministic transcript ordering.
- Preserve edits made while a save is running; report title-save failures.
  Saving only a title no longer rewrites unchanged notes.
- Wait for saved summaries before automatic generation and require a configured
  provider. Transcript animations finish after row refreshes and recording stop.

## Summaries And Local Inference

- Use one configured provider path for chat and reviewed task polishing,
  including compatible endpoint, credentials, headers, and output settings.
- Keep cancellation active through HTTP response bodies; cap API responses at
  8 MiB and reject explicitly truncated or refused output instead of saving it
  as a complete answer. Claude preserves all returned text blocks.
- Prevent duplicate summary jobs and stale cancellation state. One background
  owner persists each job's final status.
- Serialize each local sidecar request and reply so health pings cannot consume
  generation responses. Reset failed health exchanges before another request.
- Scan only appended local-model output plus stop-marker overlap, preserving
  Unicode boundaries and discarding text after the earliest stop marker.
- Remove provider response/error content and endpoint URLs from reviewed
  diagnostic paths; preserve typed status information.

## Microsoft Export Recovery

Save each pending page/task attempt before contacting Graph and checkpoint its
result immediately afterwards. Matching successful exports survive interrupted
batches without being recreated. Invalid or unavailable history blocks export.
Unknown submissions require destination review and are not automatically retried.
OneNote retains a section when a page may have been created. See
[export recovery](../integrations/microsoft-graph.md#export-history-and-recovery).

## Measured Performance And Validation

A synthetic SQLite fixture with 150,000 transcript rows across 30 meetings,
100-row pages at offset 2,500, and 31 samples reduced the median count-plus-page
query from **12.813 ms to 0.342 ms** after adding the meeting/audio/id index.
The query plan no longer scans the whole table or builds a temporary sort.
Clean and upgrade migration checks retained all rows and page results.
This measures database paging only, not app-wide latency or transcription speed.

Frontend typechecking, **70 frontend tests**, the production frontend build,
workspace Rust formatting, icons, workflow-policy regressions, and the public
repository safety scan passed. The Windows GPU preflight also passed locked Rust checking and **293 native
tests** (0 failed, 2 optional tests ignored). Required suites cover summary/provider
responses, synthetic sidecar pipes, helper stop markers, model switching, batch
cancellation, transcript preservation/persistence, credentials, export recovery,
and updater selection. Publication requires the designated Windows runner's
GPU preflight, installer build, native tests, and downloaded artifact checks.
The release verification assets identify the exact build and test results.

## Installation And Update Behavior

Runtime, installer, and updater versions are **0.5.40**, newer than 0.5.39.
Enable **Include prereleases** in **Settings > Preferences > Updates** or
**About**, or download the NSIS setup/MSI manually. Stable remains on **0.5.38**.
Disabling previews never downgrades an installed build.

The `windows-gpu` build uses Whisper Vulkan and ONNX/sherpa DirectML. The models,
dependencies, bundled Codex runtime, and active `cpal` revision are unchanged.
A supported driver or official Vulkan runtime remains a startup prerequisite.
Compilation and runtime staging do not prove active GPU inference.

Both installers include detached Tauri updater signatures, SHA-256 checksums,
build identity, and updater metadata. Updater signing is separate from Windows
publisher signing; review the release's Authenticode status. Windows security
policy still applies.

## Remaining Acceptance

Real microphone/system-audio capture, playable saved audio, prompt stop and a
second recording, graphical installation/upgrade, installed-app update discovery,
native UI accessibility/scaling, multilingual recognition and factual summary
quality, and sustained notebook memory/backlog behavior remain unconfirmed.
No capture-smoke confirmation or stable readiness is asserted.

MAI format conversion and long-recording diarization can still decode an entire
file in memory. Cancelling a request does not interrupt an already-running MAI
conversion or native inference call. The native permit remains held until that
call exits. Check generated claims against the transcript and saved audio before
sharing notes or exporting tasks.
