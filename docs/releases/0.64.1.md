# ClawScribe 0.64.1 preview

This Windows GPU patch fixes recording feedback, saved citations, and meeting notes.

## Recording

- Stop shows progress while ClawScribe finishes a recording. An explicit request to start during saving can wait up to a minute. It starts after the previous meeting is saved, and you can cancel it.
- Explicit Windows device selections stay bound to the chosen endpoint. A missing or ambiguous device can no longer silently switch the recording to the default microphone or output.
- Microphone and system-audio warnings remain visible independently. A microphone that stops delivering samples during recording now raises a warning.
- If you start a few minutes before a calendar event, you can choose it while recording. Attendance still requires review before names are used in notes.

## Meetings and notes

- Naming a speaker preserves verified summary links. Changing an unrelated passage keeps saved chat citations usable. Meeting memory can reuse unchanged passage embeddings, and questions across many meetings select evidence within the model’s context budget.
- Sidebar and Archive searches use a local index for eligible substrings and verify each match against the saved transcript.
- Editing notes preserves their generation details. The stale-notes indicator follows the transcript revision, and repeatedly pressing the generate shortcut keeps the active job visible. When a provider produces a follow-up email, you can open and copy it.
- Planner and To Do previews tell you when a regenerated summary has suggestions to review. Archive row menus provide the existing tag and delete controls with their usual confirmation.
- Hosted model settings distinguish rejected credentials, denied catalog access, and an unavailable provider. A fallback list cannot confirm a key.

## Setup and providers

- Browsing or downloading a speech model keeps the current selection. **Use** switches after the preference is saved. **Test this PC** distinguishes comparable measurements from runs on different backends.
- Onboarding shows download progress for the requested model and checks whether it is ready. **Record audio now** stays available offline. Fresh installations show when no summary model has been selected.

## Updating

Use the x64 setup executable or MSI, or turn on **Include prereleases** and check for updates. The numeric installer and updater version is **0.64.1**. The stable channel continues to offer **0.5.58**.

The Windows checks cover the full non-ignored native library suite and packaged-binary acceptance. The installed capture check makes two short recordings with independent virtual microphone and system-audio signals. It verifies that Stop saves each meeting and that both signals are present when the saved audio is decoded.

Physical microphone quality, device reconnect, sleep and wake, real conferencing calls, and the two-hour notebook comparison remain outside this preview’s automated coverage.
