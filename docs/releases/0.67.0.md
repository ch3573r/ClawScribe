# ClawScribe 0.67.0

## Markdown export

Open a saved meeting and choose **Export → Markdown (.md)**. Save the summary, the edited transcript or both as one file on this computer. The file includes the date, duration, confirmed attendees, project tags, and timestamped notes and bookmarks when the meeting has them. It works offline.

## Conversation during a recording

**Conversation** appears beside the live transcript. It shows talk time for you and others, your speaking pace, questions asked and your longest uninterrupted stretch. Everything is computed on this PC from finalized transcript lines and is cleared when the recording ends.

The split between you and others needs **Label lines as Me or Participants** under **Settings → Transcription**. Speech without a clear source, such as crosstalk, is left out of the split. When it passes a quarter of the speech time, the readout shows overall figures only. Questions are estimated from punctuation, and pace is unavailable for languages written without spaces. Hide the readout under **Settings → Recording**.

## Webhook

**Settings → Webhook** sends a finished meeting to your own automation, such as n8n, Zapier or an internal endpoint. It is off by default and has one destination.

- Send when a summary is ready, when a recording or import is saved, or both.
- The summary and action items are included. The transcript is included only when you turn it on.
- The destination address and the optional signing secret are kept in the Windows credential store. Settings show only the host.
- HTTPS is required. Plain HTTP needs your explicit consent and is never allowed to a public host. Redirects are not followed.
- **Send test** posts sample data. **Export → Send to webhook** sends one saved meeting on request.

The [webhook guide](../integrations/webhook.md) documents the payload, headers, signature and retries.

## OpenClaw integration removed

The OpenClaw meeting handoff and the **OpenClaw managed auth** summary provider are removed. The service they depended on is no longer available.

- If OpenClaw was your summary provider, choose another under **Settings → Summary**. Automatic notes wait until you do. Nothing is sent to another provider on your behalf.
- Handoff delivery history is deleted during the upgrade. Meetings, transcripts and notes are unchanged.
- A saved OpenClaw token is removed from the Windows credential store on first start when Windows allows it.
- Use the webhook to send meetings to your own automation.

## Floating recording controls

The floating window is now a compact bar with elapsed time, both audio levels, Pause, Note, Stop and Close. A note field, warnings and save progress appear only when needed. Drag the bar to move it.

The bar closes when the recording has saved. A recording without live text no longer leaves the window open. If a recording needs review, the bar stays with **Open ClawScribe** and **Dismiss**.

## Notes generated on this PC

Notes from Built-in AI or Ollama show a reminder to check tasks, owners and dates against the transcript. The reminder is hidden after you edit the notes.

## Starts on a clean Windows installation

The installers now place the Microsoft Visual C++ runtime beside the app. Versions up to 0.66.1 exited at launch without a message on a Windows installation that did not already have the Visual C++ Redistributable. No administrator prompt or download is needed.

## Remaining validation

Automated checks passed on this source: the native library tests, the frontend tests and the repository checks. The features above were not exercised in an installed build before these notes were written. Record the installed checks in [Windows release](../windows-release.md#required-real-device-acceptance) against the exact build before promoting it to the stable channel.

- **Long recordings.** The 0.66.1 notes reported eight weak or missing system-audio markers in a two-hour recording. Offline analysis of that saved recording found all 80 system markers intact at full level. The test's microphone feed had drifted about four seconds, so its louder marker overlapped the system marker and the verifier counted only the louder tone. No audio loss was found. The comparison with live assistance enabled has not run, so the effect of assistance on memory in long meetings is unmeasured.
- **Local notes quality.** Local Standard Meeting Notes can omit an agreed task or present an unsupported relationship as fact. A 4B and a 9B local model both did so on the same fictional meeting, and the same errors occur in 0.65.1. Check commitments, owners and deadlines against the transcript before using a draft or exporting actions.
- **Conversation.** The split between you and others has not been checked with a real microphone and system-audio recording.
- **Webhook.** Delivery to a real HTTPS endpoint and storage of the destination in the Windows credential store have not been checked on an installed build.
- **Floating controls.** Dragging, placement across display scaling and automatic closing were checked in rendered screenshots and unit tests, not in an installed recording.
- **Upgrade.** Removal of the OpenClaw settings and token has not been checked against an upgraded Windows profile.

## Updating on Windows

Install the Windows x64 GPU build with the setup executable or MSI. Both installers have detached updater signatures. Existing libraries upgrade in place. A database opened by 0.67.0 cannot be opened by an earlier version.
