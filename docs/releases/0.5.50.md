# ClawScribe 0.5.50 Preview

This Windows GPU preview makes saved meetings easier to browse, fixes questions failing with “Knowledge source changed” after indexing completed, and shows what the optional search-model download is doing. Meetings now opens the archive, with a separate **Meeting memory** tab for transcript search and cited questions. The page also scrolls within the available window height.

## Meeting memory

Use the searchable meeting picker and selected chips to choose sources, or explicitly select all saved meetings. Project and inclusive date filters still constrain that scope. The first question creates a saved conversation automatically; existing conversations remain available. A retry after a history-read failure keeps the original request identity to avoid duplicating a saved answer.

Ready transcripts can now supply answer context after their indexing jobs finish. Paused or failed indexing does not invalidate a saved transcript. Actual source edits, generation changes and deletion still reject stale context.

**Settings → Meeting memory** separates model transfer progress, integrity verification and index counts. It shows downloaded bytes and the current file, offers cancellation across settings navigation, and replaces the healthy-state repair button with **Verify installed files**. Verification keeps healthy files and downloads only missing or invalid ones. Cancellation preserves completed status and cannot cancel a newer transfer.

The pinned multilingual E5 ONNX model and tokenizer total about 465 MiB. ONNX Runtime runs the embedding model locally on CPU. Its tokenizer, pooling and 384-dimensional vectors must match the saved index; arbitrary ONNX models are not interchangeable. E5 finds passages, while the configured summary provider writes answers from those passages.

This preview retains [0.5.49's keyword and semantic search, saved conversations and citations](0.5.49.md). Inside an individual meeting, **Include other saved meetings** expands chat into a separate library conversation. Document attachments and live assistance remain in the follow-up plan.

Retrieval and embeddings stay local. A configured cloud answer provider receives the question and bounded selected meeting context. Answers show the actual provider/model and retrieval mode. Prior synthetic retrieval and CPU Qwen3.5 4B answer evaluations cover their fixed baselines only; answers can still omit a citation or describe a source imprecisely. Review the linked evidence.

## Preview acceptance

Focused regressions cover ready-source answers, real source invalidation, model-transfer stages, healthy-file verification, explicit source selection and automatic conversation creation. Build workflows pin a patched Node LTS version to fix a test-runner transport crash while retaining test isolation and assertions. Final frontend, native release and installer checks, independent review and artifact integrity are publication gates; published verification metadata records their exact results. Source tests do not establish installed WebView acceptance.

Exact-build scrolling at normal and reduced window sizes, tabs, meeting selection, first-question chat, download cancellation/progress, long conversations, keyboard focus, themes and recording-banner layouts remain pending manual checks. Offline retrieval, provider-failure recovery, citation navigation/audio playback, dual-source recording, clean Stop and second recording, retained meetings on upgrade, update discovery and sustained notebook/device/sleep-wake acceptance also remain pending before stable promotion.

## Installation and updates

The numeric installer, runtime and updater version is 0.5.50, greater than 0.5.49. Stable remains 0.5.48; previously published installers remain unchanged. After publication, enable **Include prereleases** to discover this preview or install manually. Drafts are excluded from updates. The updater uses the NSIS setup; an MSI is also included. Finish recording and saving before installing.

The Windows GPU profile uses Whisper Vulkan and ONNX/sherpa DirectML. Meeting embeddings and the evaluated local answer helper use CPU. Tauri updater signatures are separate from Windows publisher signing; Windows may show a publisher warning. Verify the release checksums and build metadata before installation.
