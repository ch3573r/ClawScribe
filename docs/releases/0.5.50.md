# ClawScribe 0.5.50 Preview

This Windows GPU preview fixes the Meetings page that could extend beyond the window and prevent scrolling to saved meetings. The page now uses the available content height for its vertical scroll container, including when the recording health banner is visible.

## Meeting memory

This preview retains [0.5.49's meeting-memory features](0.5.49.md): keyword search, optional local multilingual E5 semantic retrieval, selected-meeting/project/date scopes, durable library conversations, and citations that reveal transcript lines or seek saved audio. **Settings → Meeting memory** controls embeddings and indexing. Inside an individual meeting, **Include other saved meetings** expands chat into a separate library conversation. Document attachments and live assistance remain in the follow-up plan.

Retrieval and embeddings stay local. A configured cloud answer provider receives the question and bounded selected meeting context. Answers show the actual provider/model and retrieval mode. Prior synthetic retrieval and CPU Qwen3.5 4B answer evaluations cover their fixed baselines only; answers can still omit a citation or describe a source imprecisely. Review the linked evidence.

## Preview acceptance

The one-line scroll fix passed independent source review, frontend typecheck, a production build and all 250 frontend tests. Final installer preflight, native release checks and artifact integrity are separate publication gates; published verification metadata records exact results. These automated checks do not establish installed WebView scrolling acceptance.

Exact-build scrolling at normal and reduced window sizes, expanded meeting selection and long conversations, keyboard focus, themes and recording-banner layouts remain pending manual checks. Offline retrieval, provider-failure recovery, citation navigation/audio playback, dual-source recording, clean Stop and second recording, retained meetings on upgrade, update discovery and sustained notebook/device/sleep-wake acceptance also remain pending before stable promotion.

## Installation and updates

The numeric installer, runtime and updater version is 0.5.50, greater than 0.5.49. Stable remains 0.5.48; previously published installers remain unchanged. After publication, enable **Include prereleases** to discover this preview or install manually. Drafts are excluded from updates. The updater uses the NSIS setup; an MSI is also included. Finish recording and saving before installing.

The Windows GPU profile uses Whisper Vulkan and ONNX/sherpa DirectML. Meeting embeddings and the evaluated local answer helper use CPU. Tauri updater signatures are separate from Windows publisher signing; Windows may show a publisher warning. Verify the release checksums and build metadata before installation.
