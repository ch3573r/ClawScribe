# ClawScribe 0.5.53 preview

This Windows GPU preview adds reference documents to saved-meeting memory and
fixes audio test/status feedback. It builds on [0.5.52](0.5.52.md). Stable
remains 0.5.48; manual live assistance is the next phase.

## Reference documents

Attach PDF, DOCX, UTF-8 text and Markdown files in Meeting details. Preview the
locally extracted text, then explicitly select files in Meeting memory or the
expanded meeting chat. Keyword retrieval works without a model download;
semantic retrieval uses the optional local search model. Document citations
show actual extracted pages/paragraphs separately from transcript/audio sources.

Parsing runs locally in a short-lived child, bounded to 10 seconds and 512 MiB
process memory. Limits include 25 MiB input, 2 MiB extracted text/IPC, 500 PDF
pages, 32 MiB DOCX decompression and 5 MiB per XML entry. Scanned or encrypted
PDFs, malformed inputs and empty extraction report errors. OCR is not included.

Reference sharing is off by default for each conversation owner. Enable
**Allow reference context** before an external provider receives selected
excerpts. Turning sharing off cancels an active request; changing selections
excludes prior document context from later questions. Written material remains
evidence rather than instructions or a claim about what was spoken.

Version-2 backups carry originals, canonical blocks, attachment relations and
saved citations. Version-1 archives still restore. Restore validates hashes,
paths and ownership, remaps collisions and rolls back failed publication.
Derived indexes rebuild; model files, credentials and sharing permissions are
excluded. Files with identical hash/format but conflicting canonical extracted
text require a separate library rather than overwriting existing text.

## Audio feedback

Settings microphone tests now fall back to the Windows default when a saved
endpoint is unavailable and identify the actual opened device. A recording
system-audio silence warning clears when non-silent system audio arrives later;
other recording warnings remain visible. Capture, mixing, saving and Stop are
unchanged. These fixes do not establish that a particular saved recording
contains both audio sources; check playback on the exact preview.

- Backup and restore: original documents and old/new archive restoration.

Check light/dark/accent themes, keyboard focus, loading/disabled/error states and

## Validation and updates

Designated-runner frontend/native, parser/child-process, privacy, canonical
citation and archive tests validate source behavior. Real-provider factual
accuracy and installed document/citation/backup workflows remain pending;
synthetic prompt tests do not prove a model will always follow evidence rules.
The published verification record gives exact preflight/build/check results.

Installed dual-source capture/playback, clean Stop and a second recording,
retained meetings on upgrade, update/signature acceptance and sustained
notebook/device/sleep-wake recovery remain pending before stable promotion.
This preview does not establish stable readiness or capture-smoke confirmation.

The installer/runtime/updater version is 0.5.53. Stage a draft, verify both
installers, detached Tauri signatures, checksums, build identity and updater
manifest, then publish as a prerelease with latest=false. Stable remains
0.5.48. Enable **Include prereleases** or install manually; drafts are excluded
from updates. Finish recording and saving before installation. Tauri updater
signatures are separate from Windows publisher signing. The release profile is
windows-gpu: Whisper Vulkan and ONNX/sherpa DirectML; meeting embeddings use CPU.
