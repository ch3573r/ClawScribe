# ClawScribe 0.68.2-preview.1

This Windows GPU prerelease builds on 0.68.1-preview.1 with better action
items in meeting notes and faster builds. It is for manual evaluation and does
not advance the stable update channel. Everything in the
[0.68.1-preview.1 notes](0.68.1-preview.1.md) still applies.

## Meeting notes

- Summaries from Codex and OpenAI-compatible providers list every explicit
  commitment as an action item, including short ones such as "I will send the
  draft". The speaker is named as owner only when the transcript identifies who
  is speaking.
- Facts are no longer linked just because they are mentioned close together or
  cite the same passage.
- Each action item keeps the source tag of its supporting passage, so it links
  back to the transcript.
- Relative deadlines are resolved against the meeting date as before. No extra
  model requests are made.

## Builds

- Release builds compile the app in parallel, skip two unused library outputs
  and no longer build the frontend twice. Development builds keep less
  dependency debug information.

## Validation and limitations

The self-hosted runner repeats native validation, frontend tests and the
packaged installer checks for this build. The change to action items has not
been compared on real meetings.

The real-hardware checks listed for 0.68.1-preview.1 are still pending. They
include starting on a PC without any Vulkan runtime, dual-source capture with
pause, resume and stop, floating controls on mixed-DPI monitors, Teams and Meet
join flows, live Microsoft 365, Confluence and webhook exports, and exit while
automatic notes are running. Do not treat the preview as stable-ready.

## Install and update

Use the Windows x64 setup executable or MSI. The `windows-gpu` profile uses
Vulkan for Whisper and DirectML for ONNX engines. Detached updater signatures
are separate from Windows Authenticode signing; an unsigned installer may
trigger a Windows warning.

Enable **Include prereleases** in Updates to discover this build, or install it
manually. The release tag is `0.68.2-preview.1`; installer filenames, Windows
and `latest.json` use numeric version `0.68.2`, so it updates 0.68.1-preview.1
in place. Stable-only installations remain on 0.67.0.
