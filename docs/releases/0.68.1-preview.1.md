# ClawScribe 0.68.1-preview.1

This Windows GPU prerelease follows a full product, workflow and engineering
review of 0.68.0-preview.1. It fixes startup, exit and data-loss defects,
speeds up recording and playback, and improves daily meeting workflows. It is
for manual evaluation and does not advance the stable update channel.

## Startup, exit and reliability

- The GPU build starts on PCs without a Vulkan runtime. Whisper checks the
  Vulkan runtime and device first in a separate process and reports clearly
  when it cannot run; Parakeet works without Vulkan.
- Parakeet uses DirectML automatically when a short startup check in a separate
  process succeeds. A failed or crashed check falls back to CPU and is not
  repeated after crashes. Explicit DirectML or CPU choices always win.
- Fixed a DirectML length mismatch that stopped some Parakeet fp16
  transcriptions.
- The built-in AI helper is tied to ClawScribe's lifetime, is restarted once if
  it closed itself while idle, and is stopped cleanly on exit.
- Automatic notes that are running or due when ClawScribe closes are paused and
  resume on the next start instead of failing.
- Live Assistance recaps fit long meetings into the model's window instead of
  failing.

## Recording and review

- Fewer re-renders and no idle polling during recording and playback.
- Recording controls, floating controls, the sidebar start and import feedback
  are clearer; pause, resume and bookmark are available from the command line.
- A signal check before recording, simpler onboarding, and Join and record for
  Google Meet.
- Meeting review: citations, bookmarks, Find in the focused pane, and summary
  regeneration. Speaker labelling and playback controls are improved.
- Meeting memory, meeting chat and Live Assistance give more relevant answers.
- Action items flow through to follow-up emails, which open in your email
  client after review.

## Library, exports and settings

- Command palette, Settings search and Archive bulk actions.
- One metadata format for Markdown, Word, OneDrive, OneNote and Confluence
  exports; Word keeps formatting; five new summary templates.
- Recurring series, iCalendar relinking and the local MCP server are upgraded.
- Microsoft 365 exports avoid duplicates and accept all valid destination IDs.
- Playback works only from trusted recording folders, with a clear message
  otherwise.
- Settings for speech and summary models are reorganized, and keyboard
  accessibility is improved throughout.

## Validation and limitations

Local validation: 1,803 Rust library tests, the helper tests and 1,181 frontend
tests pass; the self-hosted runner repeats native validation and installer
checks. The changes were reviewed by several independent model reviews and the
findings fixed.

Not yet tested on real hardware with this build: start on a PC without any
Vulkan runtime, dual-source microphone and system-audio capture with pause,
resume and stop, floating controls on mixed-DPI monitors, Teams and Meet join
flows, live Microsoft 365, Confluence and webhook exports, and exit while
automatic notes are running. Data written by this build is not guaranteed to
be readable by older versions. Do not treat the preview as stable-ready.

## Install and update

Use the Windows x64 setup executable or MSI. The `windows-gpu` profile uses
Vulkan for Whisper and DirectML for ONNX engines. Detached updater signatures
are separate from Windows Authenticode signing; an unsigned installer may
trigger a Windows warning.

Enable **Include prereleases** in Updates to discover this build, or install it
manually. The release tag is `0.68.1-preview.1`; installer filenames, Windows
and `latest.json` use numeric version `0.68.1`, so it updates
0.68.0-preview.1 in place. Stable-only installations remain on 0.67.0.
