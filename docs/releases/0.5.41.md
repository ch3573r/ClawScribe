# ClawScribe 0.5.41 Preview

This Windows x64 prerelease updates the AI models ClawScribe offers and fixes
requests that current OpenAI and Claude models rejected or cut short. It bundles
Codex app-server 0.157.0, which adds GPT-6 Astra, Sol and Luna to the Codex
model picker.

## Current OpenAI And Claude Models

- OpenAI GPT-5 and later, and o-series models, reject `max_tokens` and
  non-default temperature/top-p on Chat Completions. The OpenAI-compatible
  provider now sends `max_completion_tokens` and omits sampling settings for
  those model families, so current OpenAI models no longer fail with HTTP 400.
  Other compatible endpoints keep `max_tokens` and their configured sampling.
- Current Claude models think before answering by default, and thinking counts
  toward the output limit. The Claude output cap rises from 2,048 to 16,000
  tokens so summaries are not cut off. Only generated tokens are billed.
- Reasoning models spend part of the output limit on reasoning. With the
  OpenAI-compatible defaults (8,192-token context, 2,048 output tokens), raise
  **Context window** and **Maximum output tokens** in the advanced settings
  before choosing a GPT-5 or GPT-6 model for long meetings.

## Model Lists

- Claude suggestions are Claude Opus 5, Sonnet 5, Haiku 4.5 and Fable 5.1,
  replacing Claude 3.5 Sonnet and Opus 4.1, which Anthropic has retired.
- OpenAI suggestions are GPT-6 Sol, Luna and Astra, GPT-5.6 Sol and Luna,
  GPT-5.5 and GPT-4o mini, replacing GPT-3.5/GPT-4-era models.
- Groq suggestions are Llama 3.3 70B and GPT-OSS 120B/20B, replacing Llama 3.1
  70B, Mixtral 8x7B and Gemma 2 9B, which Groq has shut down.
- Live model lists skip image, transcription, live-voice and text-to-speech
  models that cannot write summaries.
- The default OpenAI-compatible model remains GPT-4o mini, a non-reasoning model
  that works with the default context and output settings.

## Codex App-Server

- The Codex model picker shows the live catalog from the bundled app-server,
  including every page, instead of a built-in list that hid newer models. If
  the catalog cannot load, it shows the configured model and the error.
- Codex app-server is updated from 0.144.1 to **0.157.0**. The request and
  notification fields ClawScribe uses are unchanged; newer fields are additive.
  The catalog now includes GPT-6 Astra, Sol and Luna. The default Codex model
  remains GPT-5.6 Sol.
- The optional Codex voice host introduced in 0.157.0 is not bundled.
  ClawScribe only runs text turns, and the voice host carries separately
  licensed GStreamer/GLib and Microsoft Visual C++ runtime libraries.

## Validation

Frontend typechecking, **70 frontend tests**, workspace Rust formatting, and the
public repository safety scan passed. The Windows GPU preflight on the designated
build machine passed locked Rust checking and **296 native tests** (0 failed,
2 optional tests ignored), including new request-shape tests for OpenAI
reasoning models and other compatible endpoints. Required suites cover
summary/provider responses, sidecar exchanges, model switching, transcript
preservation/persistence, credentials, export recovery, and updater selection.
Publication requires the designated Windows runner's installer build, native
tests, and downloaded artifact checks.

The staged 0.157.0 sidecar was launched with ClawScribe's runtime environment and
a signed-out profile: `initialize` and `model/list` succeeded and listed GPT-6
Astra, Sol and Luna. Catalog pagination was checked against the real runtime.
Live OpenAI and Anthropic requests and a signed-in Codex meeting-processing turn
were not exercised for this release.

## Installation And Update Behavior

Runtime, installer, and updater versions are **0.5.41**, newer than 0.5.40.
Enable **Include prereleases** in **Settings > Preferences > Updates** or
**About**, or download the NSIS setup/MSI manually. Stable remains on **0.5.38**.
Disabling previews never downgrades an installed build.

The `windows-gpu` build uses Whisper Vulkan and ONNX/sherpa DirectML. Speech
models, the active `cpal` revision, and native dependencies are unchanged; the
bundled Codex runtime changes as described above. A supported driver or official
Vulkan runtime remains a startup prerequisite.

Both installers include detached Tauri updater signatures, SHA-256 checksums,
build identity, and updater metadata. Updater signing is separate from Windows
publisher signing; review the release's Authenticode status. Windows security
policy still applies.
