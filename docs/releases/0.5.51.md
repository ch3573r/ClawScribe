# ClawScribe 0.5.51 preview

This Windows GPU preview improves answers across selected meetings and simplifies
Meeting memory, chat and local-search settings. It builds on
[0.5.50](0.5.50.md), with no change to the stable 0.5.48 channel.

## Answer coverage and citations

When the configured answer provider's input budget permits, questions receive
all selected transcript rows in date order. Larger selections use retrieval
that reserves up to three available matches for each selected meeting before
adding passages by rank. A selected meeting with no matches receives its saved
summary as explicitly non-citable overview context. The answer must attribute
that overview to the saved summary; it cannot use it as proof of a decision.

Evidence maps support up to 1024 entries. The new additive database migration
preserves existing knowledge rows, indexes and triggers. Older backups and
saved conversations retain their citations. Canonical source resolution and
stale/historical-source checks remain in place.

Answers render markdown with bold text, lists and small numbered source chips.
Each chip opens its source; its tooltip shows the meeting title and time.
Preceding-question context uses a separate muted question chip. Raw HTML is
displayed as text. Accepted questions clear the input; failed requests restore
the question for retry. A single conversation menu uses the first question and
date for names, with New and Clear actions. Model names are friendly, while
provider and retrieval details are available in a tooltip.

## Meeting memory and settings

The archive and Meeting memory use shared tabs. Meeting memory puts a full-width
chat and pinned input below compact source controls. The project filter belongs
with Sources; searchable meeting selection, truncated source chips and a date
popover keep scope explicit. Transcript search is an optional section. Ready
semantic indexing defaults to semantic plus keyword search; keyword search
remains available without a model download.

Settings separates Semantic search and Index cards. Shared switches, progress
bars and applicable actions replace the old native controls. Verify and Rebuild
belong in overflow menus; pause, retry and resume appear when relevant. Status
refreshes automatically. The optional local model runs on this PC, supports
English and German, and downloads about 465 MB. Its repository ID appears only
in model details. ONNX embeddings run on CPU; the configured summary provider
writes the answer. Cloud answer providers receive the question and bounded
selected context, while retrieval and embeddings remain local.

The changed Meeting memory screens use shared controls and theme tokens. A CI
scanner rejects increases in raw palette colors, hex literals and native
controls against a committed baseline of existing UI debt. Document attachments
and live assistance remain follow-up work.

## Validation and pending acceptance

Focused regressions cover two selected meetings with 330 transcript rows each,
provider-budget fallback with coverage for both meetings, non-citable saved
overviews, markdown/raw HTML, a clickable citation above entry 64, and a
700-entry conversation backup round-trip. Migration tests compare all knowledge
table row counts and exact index/trigger definitions, check foreign keys, accept
ordinal 700, reject 1025, and restore a populated 0.5.50 backup.

Frontend, native Windows GPU preflight, installer and uploaded-asset integrity
checks are publication gates. Published verification metadata records their
exact results. Synthetic provider/context tests do not establish the quality of
an installed answer using real meetings.

Installed broad-question coverage across two real meetings, markdown/citation
interaction, scrolling and long conversations, source selection, keyboard focus,
light/dark/accent themes and layouts at 1000 px and wider remain pending. So do
offline retrieval, provider-failure recovery, source navigation/audio playback,
dual-source recording, clean Stop and a second recording, retained meetings on
upgrade, installed update discovery, and sustained notebook/device/sleep-wake
acceptance. This preview is for manual evaluation and does not establish stable
readiness or capture-smoke confirmation.

## Installation and updates

The numeric installer, runtime and updater version is 0.5.51, greater than
0.5.50. After draft staging and asset verification, this release is published as
a prerelease with latest=false. Stable remains 0.5.48. Enable **Include
prereleases** to discover the published preview or install manually; drafts are
excluded from updates. Finish recording and saving before installation.

The release includes NSIS and MSI installers, detached Tauri updater signatures,
checksums, build metadata and the updater manifest. The Windows GPU profile uses
Whisper Vulkan and ONNX/sherpa DirectML. Meeting embeddings use CPU. Tauri updater
signatures are separate from Windows publisher signing; Windows may show a
publisher warning. Verify the release checksums and build metadata before use.
