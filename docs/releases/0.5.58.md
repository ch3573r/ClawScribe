# ClawScribe 0.5.58 preview

This Windows GPU preview reworks the meeting details screen, tidies the Meetings
page and the Add-ons settings, and adds Claude Code as an optional summary and
meeting chat provider. It builds on [0.5.57](0.5.57.md). Stable remains 0.5.48.

## Meeting details

- The meeting title sits in a header across the page with the date, segment count
  and tags below it, next to Export and a menu for the less common actions.
- The playback strip shows the transcript segments on the track. Speaker lanes
  stay when speaker labels (beta) are on.
- The transcript and summary toolbars are one row each. Less common actions moved
  into menus: open recording folder, enhance, undo last correction, save and
  replace text.
- Editing a transcript segment is a pencil button that appears on hover and on
  keyboard focus.
- The Bookmarks row shows only when the meeting has bookmarks. Add bookmark is in
  the transcript menu.
- The summary renders on the same surface as the pane. Section labels such as
  Summary or Key decisions sit on their own line. Links use the theme colour and
  timestamps use the mono font.
- Context for the summary moved from below the transcript to a control under the
  summary.
- Chat opens from a Chat with this meeting button under the summary. In windows
  1280 px and wider it docks beside the summary; in narrower windows it opens as a
  popup as before.

## Meetings and Meeting memory

- Each meeting in the Archive list is one link with its date and tags. The count
  reads "5 meetings", or "2 of 5 meetings" when a filter is active.
- An empty library offers Start recording and Import audio or video. A filter with
  no matches offers Clear filters.
- Meeting memory shows a Choose meetings prompt until a meeting is selected.
  Reference documents and source search are in a collapsed row.

## Settings

- Add-ons has one Microsoft 365 card with the account and Sign out. While signed
  out, the Microsoft products are listed once with "Available after you sign in".
- The OneDrive card shows the destination folder with a Change folder button. The
  folder link, subfolder and top-level folder options are in that dialog.
- A failed OneDrive folder load no longer retries without end.
- Microsoft 365, Word, OneNote, OneDrive, Planner, To Do, Teams, Outlook and
  Confluence icons use their product colours and no longer follow the accent.
- Navigation groups and "Summary language" use sentence case.

## Claude Code provider

Claude Code is a new optional provider for summaries and meeting chat. It uses the
Claude Code you installed and signed in to, and your Claude plan's limits apply.
ClawScribe does not bundle Claude Code, sign in for you or read its credentials.
The selected meeting text is sent to Claude's service; this is not offline
inference. Choose it under Summary in Settings, then pick Sonnet, Opus or Haiku.
See [Claude Code](../auth/claude-code.md).

## Dialogs, contrast and focus

- Error messages that used a browser alert are now notifications that say what
  failed and what to do next. Deleting a meeting or a recovered transcript asks in
  an app dialog.
- Error text in the dark theme is readable: contrast on the background went from
  1.89:1 to 8.87:1.
- Keyboard focus rings are 2 px and at least 3:1 against the surface with every
  accent colour.
- Decorative animation stops when the system asks for reduced motion.

## Validation, limitations and updates

Nothing in this release has been run on an installed build. The interface changes
were checked in a browser against a mocked backend in the dark theme at 1600 px:
meeting details with and without a summary, docked chat, the Meetings list, Meeting
memory and Add-ons while signed out. Playback with a real recording, Add-ons while
signed in, the OneDrive dialog, chat keyboard focus and the light theme were not
checked by rendering. A Claude Code summary has not been run end to end; only the
signed-out path was observed.

Pending before stable promotion: all of the above on an installed build, plus the
acceptance carried over from [0.5.57](0.5.57.md) and [0.5.56](0.5.56.md). Earlier
audio acceptance does not certify this build.

The installer, runtime and updater version is 0.5.58. Stage a draft, verify both
installers, detached Tauri signatures, checksums, build identity and updater
manifest, then publish as a prerelease with latest=false. Stable stays 0.5.48.
Enable **Include prereleases** or install manually; drafts are excluded from
updates. Finish recording and saving before installation. Tauri updater
signatures are separate from Windows publisher signing. The release profile is
windows-gpu: Whisper Vulkan and ONNX/sherpa DirectML; meeting embeddings use CPU.
