# ClawScribe 0.5.57 preview

This Windows GPU preview improves live transcription with Parakeet, adds a custom
vocabulary, an optional separate transcription process, Parakeet Ultra in the model
catalog and command-line recording control. It builds on [0.5.56](0.5.56.md).
Stable remains 0.5.48.

## Live transcription with Parakeet

- Speech that does not stop is now cut at a pause instead of at a fixed point.
- Parakeet live segments may run up to 12 seconds, up from 6. Text for nonstop
  speech can therefore appear up to 12 seconds late.
- An audible segment that comes back with no text is retried.
- Speaker labels (beta) are taken from each segment's own time range.

On two synthetic clips, word errors fell from 6 to 2 in English and from 6 to 5 in
German. These are the only measurements so far. The change has not been checked on
real meetings.

## Custom vocabulary

Settings has a new list under transcription for names and terms. A transcript word
close to a listed entry is replaced by the entry's spelling in live recording,
import and retranscription.

- Entries of up to 4 characters match exactly only.
- Possessive and plural endings are kept.
- Entries with umlauts work.
- The list applies to new transcripts and to retranscription. Saved transcripts
  are not changed until you retranscribe them.

## Run transcription in a separate process (beta)

A new switch in the beta settings, off by default, runs Parakeet in a child
process.

- If the speech model crashes or stops responding, the app restarts it and retries
  the segment.
- After a GPU failure, the rest of the session uses the CPU and the settings page
  says so.
- Only Parakeet uses it. Whisper and Nemotron are unchanged.

## Parakeet Ultra in the model catalog

Parakeet Ultra is a fine-tune of Parakeet v3 for 25 languages. Its published
accuracy in German and English is better than Parakeet v3: 4.58 % against 5.24 %
word error in German and 4.26 % against 4.83 % in English. Others measured these
figures; we have not run the model. It is available as 8-bit and 16-bit downloads.
The default model is unchanged.

## Command-line control

Launching the app again with `--toggle-recording`, `--start-recording` or
`--stop-recording` controls the running instance.

## Runtime and build

- The bundled Codex app-server is updated from 0.159.2 to 0.169.0.
- Release builds use link-time optimisation and stripped symbols.

## Validation, limitations and updates

Accuracy figures for the live changes come from two synthetic clips only. Nothing in
this release has been run on an installed build with real meeting audio. Parakeet
Ultra has not been run by us, and its accuracy figures are not ours. The custom
vocabulary section and the new beta switch have not been checked in light and dark
themes.

meeting audio, plus the acceptance carried over from [0.5.56](0.5.56.md). That is

installed update and signature acceptance, provider factual accuracy, and
