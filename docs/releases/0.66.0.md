# ClawScribe 0.66.0

## Recording and playback

Select the microphone and system output from **Signal path** on Home. Recording settings and tray starts use the same selections. The main window and floating controls retain the active recording, pause state and bookmarks while a device reconnects. Saved meetings show gaps, quiet system audio and unfinished live transcription.

ClawScribe now waits briefly for the second audio source before padding a mixer window. This corrects cumulative timing error from staggered callbacks. Speech detection uses bounded audio history during silence and continuous speech. Stop drains the final speech samples and preserves the recording for playback and retranscription. Short replies can still be missed or transcribed incorrectly.

A desktop Teams call can keep recording through a window change. Calls with different known rooms are handled separately. When Teams exposes neither a room ID nor an observable end between calls, adjacent calls can share a recording.

## Library, imports and recovery

Older interrupted drafts remain available when their recording folder is offline. Save a local text copy, or save a draft with a verified recording identity to the library and add its audio when the folder returns. Deleting or renaming a meeting updates the sidebar immediately. Failed file cleanup survives a restart and can be reviewed under **Meetings → Archive → Storage**. Repairing an imported meeting can rebuild its folder files from the saved database.

Audio imports run one file at a time. Cancel or retry individual files, and review any cloud upload. Starting a recording can interrupt an import.

Version 3 portable backups stream transcript history and support custom templates, vocabulary and linked series preferences. Verified live-only answers and approved series notes can travel with their meetings. Reports count omitted answers. Scheduled backups are optional and retain the three newest verified copies. Startup recovery can restore into a separate library and return to the original library. Version 1 and 2 backups remain readable.

## Search, notes and follow-ups

Open and correct the first transcript page while a long meeting's timeline loads. Search several words in one source, quote an exact phrase, or play a verified transcript match. **Ask about these results** opens an editable question scoped to the matches. Including personal excerpts requires review.

Regeneration keeps existing notes available. If translation fails, the English notes and citations remain available for a translation-only retry. Automatic notes can use the local meeting date, weekday, duration and, where privacy settings allow, the title. Previously approved external destinations require fresh approval for those details.

Use **Open actions** to filter reviewed follow-ups by owner, due date or series. Prepare for a recurring meeting using reviewed earlier occurrences. Follow-up email opens a draft for the attendees you select. Save a live answer explicitly to keep it with its recording. Deleting a source also removes saved answers that used it.

## Exports and updates

Planner and To Do retries preserve existing task notes and due dates. OneDrive tracks Word, PDF and sharing results separately. OneNote can update a reviewed saved page or create a revision. Confluence reports when a draft differs from its published page. Export history lets you verify uncertain outcomes before submitting again.

Automatic update checks follow the saved preference and channel while the app is in the tray. Installer handoff saves pending meeting titles and notes, including edits made during download. A save failure keeps the draft available and stops installation.
