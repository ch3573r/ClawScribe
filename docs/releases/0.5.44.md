# ClawScribe 0.5.44 Preview

This Windows GPU preview fixes desktop file dialogs introduced with the local
meeting library tools in 0.5.43 and includes a title-bar interaction correction.

## Changes

- Word export and backup creation can open the native Save As dialog. The missing
  Tauri `dialog:allow-save` permission previously caused an ACL error before any
  file could be written. The permission is limited to the local main window;
  restore continues to use its existing Open permission.
- A regression test checks file-picker permissions in the shipped configuration,
  covering a gap in browser tests that mock native calls.
- Title-bar dragging and double-click maximization dispatch each action once.
  Minimize, maximize, and close buttons retain their separate actions.

Project tags, bookmarks, local Word generation, and additive backup restore retain
the behavior documented in the [local library guide](../local-library.md).

## Validation and remaining acceptance

Release gates include frontend typechecking and tests, production frontend build,
public-repository safety checks, Windows GPU preflight, icon checks, and native
regressions on the designated Windows runner. The capability regression was
confirmed to fail without the Save As permission and pass with it.

Automated checks do not establish real-device dual-source recording, graphical
installation/upgrade, native file-picker acceptance, Word desktop rendering,
large-library restore, or installed-app update discovery. These require manual
evaluation; capture-smoke confirmation and stable readiness are not asserted.

## Installation and updates

Runtime, installer, and updater versions are **0.5.44**, newer than 0.5.43. Drafts
are excluded from update discovery. Once published as a prerelease, enable
**Include prereleases** or install the NSIS setup/MSI manually. The stable channel
remains on 0.5.41; changing channels never downgrades an installation.

The `windows-gpu` profile uses Whisper Vulkan and ONNX/sherpa DirectML. Audio
capture dependencies, models, and the bundled Codex runtime are unchanged.
A supported GPU driver or official Vulkan runtime remains a startup prerequisite.

Assets include both installers, detached Tauri updater signatures, SHA-256
checksums, build identity/metrics, and `latest.json`. Updater signatures are
separate from Authenticode publisher signing.
