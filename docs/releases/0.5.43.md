# ClawScribe 0.5.43 Preview

This Windows GPU preview adds tools for organizing, sharing, and preserving a
local meeting library. The stable update channel remains on 0.5.41.

## Changes

- **Export Word:** save notes, the full saved transcript, or both as a local
  `.docx`. Speaker labels and timestamps are optional. Microsoft sign-in and an
  installed copy of Word are unnecessary for generation. The current writer
  supports basic headings, bullets, and paragraphs, not all editor formatting.
- **Project tags:** assign labels from a saved meeting and filter the Meetings
  archive, including transcript search results, by project or untagged meetings.
- **Backup and restore:** export a ZIP with saved meeting records and recording
  files. Restore adds missing meeting IDs without replacing existing meetings.
  Tags, bookmarks, correction history, meeting chat, and recording-folder export
  history are retained. Models, provider settings/credentials, UI preferences,
  browser-stored meeting context, and unfinished recording spools are excluded.
  Archives are not encrypted and should be kept in trusted storage.
- **Bookmarks:** mark the current recording position, then rename, remove, and
  revisit it in the saved meeting. Add labeled timestamps during review as well.

Read [Local meeting library](../local-library.md) for limits and restore behavior.

## Validation and remaining acceptance

Release gates include TypeScript checking, 77 frontend tests, a production
frontend build, Rust formatting, the public-repository safety scan, and the
Windows GPU preflight with locked Rust checking and required native regressions.
Eight new native library tests cover archive round-trips, duplicate skipping,
unsafe paths, failed-import rollback, migration preservation, labels, bookmark
association, and deletion cleanup. Browser review uses synthetic meeting data
and mocked native calls; it does not validate installed-app behavior.

Real microphone/system-audio capture, playable saved audio, stop/restart,
installed-app bookmark timing across pauses, Word desktop rendering, large-library
backup/restore, graphical installation/upgrade, and installed-app update discovery
remain unverified. Sustained notebook performance remains unconfirmed. This
preview is for manual evaluation and does not assert capture-smoke confirmation
or stable readiness. Test a backup restore before relying on your only copy.

## Installation and updates

Runtime, installer, and updater versions are **0.5.43**, newer than 0.5.42.
Enable **Include prereleases** to discover the published preview, or install the
NSIS setup/MSI manually. Drafts are excluded from update discovery. The stable
channel remains on 0.5.41, and changing channels never downgrades an installation.

The `windows-gpu` profile uses Whisper Vulkan and ONNX/sherpa DirectML. The active
`cpal` revision, models, and bundled Codex runtime are unchanged. A supported GPU
driver or official Vulkan runtime remains a startup prerequisite.

Release assets include both installers, detached Tauri updater signatures,
SHA-256 checksums, build identity/metrics, and `latest.json`. Updater signatures
are separate from Authenticode publisher signing. Review the release's signing
status; Windows security policy continues to apply.
