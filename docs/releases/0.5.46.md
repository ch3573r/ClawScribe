# ClawScribe 0.5.46

This Windows GPU candidate includes the recording, summary, library, and safety
fixes since 0.5.45. The candidate is staged as a draft until the real-device checks
below pass; drafts are excluded from update discovery.

## Recording and recovery

Interrupted audio-only recordings can be recovered without transcripts. The
recovery dialog recognizes retained raw audio instead of incorrectly reporting
"No audio". Recovery preserves originals until the complete audio is represented
in the recovered file and falls back to WAV when compression fails. Capture-gap
warnings survive recovery; damaged status files no longer prevent retranscription.

Windows device enumeration now retains its COM apartment for the process lifetime,
fixing crashes after short-lived audio workers exit. Live transcription failures
produce one error notice per recording, and live wall-clock timestamps use local time.

## Summaries and transcript review

- Provider-aware context/output budgets, bounded reduction, retry handling, and
  reasoning-model/custom-endpoint support improve summary reliability. Source
  citations support review, and recoverable chat failures preserve useful partial
  output without duplicate assistant messages. Review generated claims against audio.
- Titles and summaries autosave across navigation. Replacing edited notes requires
  confirmation, and **Restore previous summary** recovers the previous result.
  Quit offers an explicit discard choice when pending edits cannot be saved.
- **Restore previous transcript** can undo retranscription or speaker detection.
  Speaker-label saves retain correction history and reject conflicting transcript
  changes. A failed recording-folder mirror remains available for retry.
- Speaker detection uses bounded decoding memory and can be cancelled from its
  dialog or the meeting toolbar. Cancellation waits for the current native step;
  long meetings can require several minutes before a new recording can start.

## Storage and safety

Model downloads are checked against pinned revisions, sizes, and SHA-256 hashes.
External links are validated before opening. Meeting deletion is guarded, saved
transcript recovery copies are removed promptly, and unsaved recovery copies do
not expire by age. Cleanup preserves recording folders still needed for recovery.

Summary context now lives with the meeting in SQLite and portable backups.
Database transfers preserve committed WAL data, and pending migrations receive
consistent database snapshots. Restored meetings explain when excluded recovery
files must be recovered on the original computer.

## Validation and acceptance

The preflight passed 157 frontend tests and 615 required native app tests, with
three native exclusions, plus eight helper tests. Typechecking, Windows GPU
compilation, formatting, and repository safety checks passed. Installer artifacts
must also pass checksum, build-identity, updater-manifest, and signature verification.

The owner must test this exact candidate before publication: microphone and system
audio, playable saved audio, Stop and a second recording, upgrade/data preservation,
notes, and sustained use. See the [Windows acceptance checklist](../windows-release.md#required-real-device-acceptance).
Automated tests do not establish real-device capture quality or active GPU inference.

## Installation and updates

Installer, runtime, and updater versions are **0.5.46**. Draft assets do not appear
in either update channel. After separately authorized stable publication, older
installations can discover this version without enabling prereleases. The updater
uses the NSIS setup; an MSI is also provided. Finish recording and saving first.

The `windows-gpu` profile uses Whisper Vulkan and ONNX/sherpa DirectML. A supported
GPU driver or official Vulkan runtime remains required. Tauri updater signatures
are separate from Windows Authenticode publisher signing; Windows may still show
an unknown-publisher or SmartScreen warning.
