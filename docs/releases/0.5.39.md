# ClawScribe 0.5.39 Preview

This Windows x64 prerelease adds deferred transcription and tools for reviewing
meeting transcripts and notes. It is available for manual evaluation and through
the optional prerelease update channel.

## Recording And Transcript Review

- Select **Audio only** on Home or in Recording settings to record now and
  transcribe later. This mode always saves audio and skips live recognition.
  Use **Transcribe** on the saved meeting when ready.
- Edit individual transcript passages or preview literal find-and-replace across
  the meeting. Original recognition and segment timing remain available. Undo
  restores prior text and alignment; retranscription starts a new edit history.
- Corrections are persisted transactionally. A failed recording-file mirror
  remains visible and retryable without discarding the database correction.
  Regenerate notes after correcting a transcript.

## Summary Review And Templates

- Find and replace summary text while preserving formatting and links. Review
  the changes and save; the editor's undo command can revert replacements.
- New summaries request links to supporting transcript passages. Open a link to
  inspect the passage, reveal it in the transcript, or play its saved audio.
  Corrected or replaced passages invalidate old references. Existing summaries
  need regeneration to gain references. Models can omit or misuse citations;
  check whether the passage supports the claim.
- Create or edit templates in **Settings > Summary** and choose a persistent
  default. Meetings can override that selection. Structured summary providers
  retain decisions and action fields used by exports while rendering the chosen
  template.

## Installation And Update Behavior

Runtime, installer, and updater versions are `0.5.39`. In 0.5.38, enable
**Include prereleases** in **Settings > Preferences > Updates** or **About**
to discover this preview. Stable checks remain on 0.5.38. Turning previews off
never downgrades an installed build; the next update needs a higher version.

The normal `windows-gpu` build includes Whisper Vulkan and ONNX/sherpa DirectML.
A supported GPU driver or official Vulkan runtime is required at startup.
Successful compilation does not establish active GPU inference.

Both NSIS setup and MSI installers are provided with SHA-256 checksums, build
identity, and detached Tauri updater signatures. Updater signatures do not
establish Windows publisher identity. Windows security policy still applies;
review the published Authenticode status and verification record.

## Validation And Remaining Acceptance

The implementation passed frontend typechecking, 55 frontend regressions, a
production frontend build, clean/upgrade database migration checks, and browser
checks using synthetic meetings and mocked desktop commands. These browser checks
do not exercise native recording or model inference.

Publication requires the designated runner's Windows GPU preflight, installer
build, required native regressions, and downloaded artifact integrity checks.
The release verification record identifies the exact build commit and results.
Native regression coverage includes audio-only preservation, transcript edit/undo
and file-mirror retry, stale source references, template storage, and structured
summary rendering. Full-repository Rust formatting retains pre-existing
differences in unchanged files; modified Rust files passed formatting checks.

Real microphone/system-audio capture in both recording modes, playable saved
audio, prompt stop and a second recording, graphical installation/upgrade,
native UI scaling, model-generated citation quality, multilingual recognition,
and sustained notebook performance remain unconfirmed. No capture-smoke
confirmation or stable readiness is asserted. Long-recording diarization
remains memory intensive. Review generated claims against the transcript/audio
before sharing notes or exporting tasks.
