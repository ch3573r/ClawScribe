# ClawScribe 0.65.0

## Join and record

Choose **Join and record** on a Teams invitation in Upcoming. ClawScribe opens the invitation and waits up to five minutes for its call. A newly opened browser call that matches the invitation can start recording automatically. If ClawScribe needs to confirm which call you joined, it shows the event name. **Join** remains available on its own.

**Use for next recording** now expires five minutes after the event ends. Attendance still requires review.

## Search saved meetings

Search meeting titles, transcripts, summaries, personal notes and bookmarks from the sidebar or Meetings. Open a result to return to its source. **Ask about these results** opens an empty question scoped to the displayed meetings.

To include personal notes in a question, select individual excerpts and review their exact text, provider, model and destination. Confirmation allows one send attempt. Later questions exclude that exchange from provider history. Codex and Claude Code support ordinary questions only because they manage their own connections.

Local MCP meeting search now finds mixed-case Unicode text, including German umlauts, in titles and current transcripts.

## Floating recording controls

Choose **Open floating controls** from the recording bar or tray. The window stays above other apps and shows elapsed time, microphone and system levels, bookmarks, timestamped notes and Stop. Closing the window leaves recording active. ClawScribe requests capture exclusion from Windows. Visibility can vary by screen-sharing application.

## Recording and automatic notes

Recorded meetings use the start of capture as their library date, including after an overnight recording or recovery. Imports retain their chosen date.

A capture-gap warning stays visible while a usable completed transcript can produce automatic notes. Successful retranscription can start one approved notes job, including the first transcription of an audio-only recording. If the app closes just after saving the transcript, it checks the current provider approval on restart. Completed notes are preserved.

## Updating on Windows

Use the stable updater or install the Windows x64 GPU build with the setup executable or MSI. Both installers have detached updater signatures. When upgrading from stable 0.5.58, you also receive the recording recovery, local notes, archive management and citation fixes introduced in the intervening previews. Existing libraries upgrade in place.
