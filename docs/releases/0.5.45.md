# ClawScribe 0.5.45

This Windows GPU release brings recording and recovery fixes to the Stable
channel after real-device acceptance. It includes the library tools introduced
in the intervening previews.

## Recording and recovery

Available audio survives degraded live transcription and independent file-save
failures. Stop freezes recording duration and has one owner; saving a meeting
is protected against duplicate requests. Transcript snapshots continue during
silence, and the saved library transcript can use the backend snapshot.

Final audio is encoded once with a bounded deadline scaled to recording length.
Stopped metadata is written before encoding. A readable temporary capture tail
is included in final audio and recovery; torn temporary writes leave a capture-gap
warning without retaining the whole successfully encoded spool. Unreadable
published chunks and originals needed after failed saves remain available.
Legacy checkpoint recordings remain recoverable.

Automatic notes wait for usable audio and a complete transcript. Capture gaps
and recording-file warnings remain visible without blocking notes. Retranscription
clears repaired flags only when the corresponding repairs succeed; capture gaps
remain permanent. Summary polling survives meeting updates and reports failures.

## Library, exports, and interface

- Backups report missing audio and excluded recovery originals instead of blocking
  the whole library. Restore skips existing IDs before extracting their audio,
  accepts older version-1 tables, and keeps database/file changes consistent.
- Export timestamps use positions in the recording. One export menu selects notes,
  transcript, or both for Word, OneDrive, OneNote, and Confluence. Local Word dates
  and native Save As permissions are corrected.
- Project tags and live/saved bookmarks remain local. Tag filters avoid loading
  flashes on unrelated changes, and bookmarks load even if event subscription fails.
- Title-bar gestures dispatch once. Resumable model downloads, HE-AAC timing,
  reasoning-tag filtering, and portable CPU build settings from earlier previews
  are included.

## Validation and acceptance

Automated validation includes 114 frontend tests, a production frontend build,
and 401 Windows GPU native tests with two ignored tests. New regressions cover
partial saves, metadata during encoding, legacy checkpoint recovery, readable
and torn temporary tails, spool cleanup, and repaired warning flags.

Automated tests do not prove microphone/system-audio capture, live GPU inference,
graphical installation/upgrade, generated note quality, or sustained notebook
performance. The verified candidate was published unchanged as the stable release
after the repository owner confirmed the real-device checks in
[Windows releases](../windows-release.md#required-real-device-acceptance); detailed
device and model measurements were not recorded. Native dialogs,
Word rendering, and large-library behavior also require product-level review.

## Installation and updates

Installer, runtime, and updater versions are **0.5.45**, newer than 0.5.44.
Drafts are excluded from update discovery. After Stable publication, older builds
can discover this version without enabling previews. The updater uses the NSIS
setup; an MSI is also provided. Finish recording and saving before installation.

The `windows-gpu` profile uses Whisper Vulkan and ONNX/sherpa DirectML. A supported
GPU driver or official Vulkan runtime remains a startup prerequisite. Presence of
a loader or adapter does not prove accelerated inference. Updater signatures are
separate from Authenticode publisher signing; Windows may show a publisher warning.

Release assets include both installers and their detached updater signatures,
SHA-256 checksums, build identity/metrics, and `latest.json`. Verify them against
the exact candidate before acceptance; unchanged verified binaries are promoted.
