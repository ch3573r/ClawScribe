# ClawScribe 0.5.36

Changes from the published 0.5.35 tag (`e836d88`). See
[GitHub Releases](https://github.com/ch3573r/ClawScribe/releases) for publication
status, installer assets, checksums, and the final build-validation record.
A source version or this document alone does not certify a successful release.

## Meeting Content And Notes

- Fixed shared-summary chunking that could skip source text after a sentence or
  word boundary. Chunks advance from the actual emitted boundary, preserve UTF-8
  boundaries, and cap redundant overlap.
- The shared processor rejects empty transcript input and failed, empty, or
  thinking-only chunk output instead of reporting incomplete notes as complete.
  Cancellation remains cancellation. Resumable per-chunk retry is not included.
- Shared extraction, combination, and report prompts now request concise factual
  notes, retain negation/uncertainty, distinguish proposals from decisions, and
  avoid invented owners/deadlines. Dedicated OpenAI-compatible/Codex routes have
  separate implementations. Prompt changes are not a measured accuracy gain.
- Removed the transcript-view filter that hid meaningful words such as German
  `er` and `um`. This is a presentation fix, not a rewrite of stored recognition.
- Included the previously unreleased fix replacing length-derived Whisper
  confidence with mean model token probability and retaining nonempty short
  utterances instead of discarding them solely for low confidence.

## Transcript Usability

- Improved following of tall new transcript rows, cancellation of delayed scroll
  work on interaction/cleanup, and repeated search-result navigation behavior.
- Added **Jump to live transcript** when reviewing earlier text during recording;
  explicit navigation respects reduced-motion preferences where applicable.
- Replaced nested transcript-row button semantics with a native timestamp playback
  button and associated custom speaker labels with their input.
- Speaker saves prevent duplicate submissions, report actionable errors, and keep
  custom input until persistence succeeds.

## Resources And Credentials

- Measure physical RAM through the existing `sysinfo` dependency while retaining
  the diagnostic environment override. Windows Whisper's adaptive policy caps
  inference at four threads for detected memory values at most 8 GiB, eight
  otherwise, and one fewer than logical parallelism where possible (minimum one).
  This is not an app-wide resource cap or a measured notebook speed guarantee.
- Bound best-effort diagnostic logging, flush quiet batches periodically, and
  avoid formatting disabled messages. Audio capture is not changed to a lossy
  queue. Previously unreleased duplicate log targets and an unused audio-level
  metrics accumulator are also removed.
- Protect Windows Microsoft refresh-token file fallback with current-user DPAPI.
  Legacy plaintext migration is attempted on read and removed after successful
  encrypted persistence; failed migration can leave the legacy file in place.
  Non-Windows platforms do not write a new plaintext fallback. This does not
  encrypt recordings or the meeting database.

## Build And Documentation

- Fix Windows GPU native-test startup on hosted runners by explicitly installing
  and verifying the signed Vulkan runtime bundled with the pinned SDK. SDK
  extraction alone left `vulkan-1.dll` missing. Native tests now report that
  prerequisite before compilation/discovery; local tests do not install it
  implicitly. The application installer still requires an existing GPU driver
  or official Vulkan runtime and does not bundle either.
- Fix native Windows test execution by explicitly loading the same staged
  sherpa/ONNX runtime DLLs as the installer; keep tests mandatory and run them
  against release-profile code.
- Align application version metadata to 0.5.36. There is no general dependency
  refresh: the previously unreleased DPAPI fix adds the direct Windows API
  dependency/reference, and the application version advances in `Cargo.lock`.
  The frontend dependency lockfile is unchanged from 0.5.35.
- Make unsuccessful native commands fatal and require both current-version
  installers. Keep frozen frontend and locked Cargo builds.
- Add source regressions and native summary/resource tests to candidate staging,
  plus an optional hosted Windows runner and draft release staging with exact
  build identity, checksums, and updater metadata.
- Update the README and product/build guides for actual credential storage,
  toolchain and helper staging, source versus published versions, transcript
  controls, and the scope of notebook tuning and test evidence.

## Validation And Limitations

Application source checks passed frontend typechecking and 32 configured frontend
cases. Isolated production Rust checks passed 43 distinct tests (48 executions;
chunker cases ran twice). The provider boundary was stubbed, and frontend controls
used deterministic mocks rather than a rendered Windows UI.

The [published prerelease](https://github.com/ch3573r/ClawScribe/releases/tag/v0.5.36)
records the successful complete Windows build and four required native test
groups for binary commit `1d92be1122bdcf0a6f93ed47e4981a3836e215a1`.
Its `RELEASE-VERIFICATION.json` records downloaded-asset SHA-256 verification
and verification of the NSIS Tauri updater signature against that commit's
public key. Later documentation changes do not relabel or replace those binaries.

Real microphone/system-audio capture, graphical installer/upgrade acceptance,
Windows accessibility/scaling,
and sustained i5-1235U/8 GB performance remain unconfirmed for this prerelease.

Provider-wide context budgeting, resumable reduction, evidence-linked actions,
and a measured multilingual accuracy improvement are not delivered by this patch.
Review generated notes before exporting. Stable publication still requires the
real dual-source recording acceptance test; a compiled candidate is not that test.

Read the release's signing status. Tauri updater signatures and Authenticode are
different; an updater signature alone does not establish a trusted Windows
publisher. Never replace published binaries under an existing version tag.
