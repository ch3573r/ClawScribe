## Windows packaging gate

The release branch stages a **draft** through the existing Windows build workflow.
It must build both installers, run the selected tests in the actual native crate,
and create checksums, build metadata, and signed updater metadata. Any failed
native command must stop staging. The draft must not change the stable updater.

## Publication gate

Before public publication, a real Windows test must capture both microphone and
system audio, stop cleanly, and produce playable audio. The workflow's existing
capture-smoke confirmation remains required and has not been asserted by automation.
Also verify install/update, UI keyboard interactions and scaling, and sustained
meeting performance on the target i5-1235U / 8 GB notebook. No hardware performance
measurement is claimed by the conservative thread-budget change.
