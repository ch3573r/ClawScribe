# ClawScribe 0.64.0 preview

You can start a first recording without downloading a speech model. Stop saves
the meeting to the library before reporting success. If saving is interrupted,
recovery can finish the handoff using the same recording ID, including the
meeting’s attendance and timestamped notes.

## Recording and playback

- **Record audio now** opens Home in audio-only mode. Speech and local notes
  models can be added later. Home shows the selected live engine and devices.
- Tray and shortcut starts preserve the page you are using. The tray shows
  whether recording is starting, paused, or saving. A failed input can reconnect
  while the other source continues. The saved meeting retains a capture-gap
  warning when audio was lost.
- Search from the sidebar or Archive to jump to a matching transcript passage.
  Change playback speed, follow the spoken passage, or add a timestamped note.
  Notes stay local unless you enable their use as summary priorities for that
  meeting. That option shares the first 40 notes in timestamp order.
- Retranscription keeps the previous text and retries interrupted file updates.
  The optional hosted MAI path prepares and streams audio in bounded chunks.

## Attendance, notes, and follow-up

- A unique ongoing event can be associated after recording starts. An explicit
  choice takes precedence. Review attendance before names are used in a summary.
  Recurring Microsoft and iCalendar meetings can have their own summary templates.
- Automatic notes run against a saved transcript. A change to an external
  destination requires fresh approval. You can see progress, inspect successful
  excerpts after a failure, or retry. Imported files can have their own notes
  choice and meeting date.
- Add or edit follow-up actions offline before selecting tasks for Planner or
  Microsoft To Do. An ambiguous match with an older export is held for review.
  Export history travels with library backups, and interrupted OneNote exports
  can resume with the saved section.
- Archive shows meetings that need attention and measures saved audio on demand.
  You choose and confirm which verified app-owned audio copies to remove.
  Settings also offers a small diagnostics report that omits meeting content.

## Getting the preview

For Windows x64, use the setup executable or MSI below. To receive this release
in the app, enable **Include prereleases** in the update settings and check for
updates. The numeric installer and updater version is **0.64.0**. The stable
channel continues to offer **0.5.58**. Finish recording, saving, or exporting
before installing.

The packaged automated checks recovered synthetic audio with the bundled
encoder, imported an audio fixture, generated notes against a loopback test
provider, and reopened the saved results in a second process. Windows
microphone and system-audio capture, physical sleep and reconnect, installer
and updater interaction, real provider and Microsoft 365 operations, and the
two-hour notebook comparison still need hands-on evaluation.
