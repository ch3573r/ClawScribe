# ClawScribe 0.69.0-preview.1

This Windows GPU prerelease follows a pre-production review of the whole app.
It fixes recording, transcription and privacy problems the review confirmed,
and adds recoverable delete, encrypted backups, subtitle export, launch at
sign-in and opt-in speaker profiles. It is for manual evaluation and does not
advance the stable update channel. Everything in the
[0.68.2-preview.1 notes](0.68.2-preview.1.md) still applies.

## Recording

- **Stop** reports when nothing was recording, so the controls no longer stay
  on "Stopping". A stalled device reconnect no longer blocks saving: Stop saves
  what was captured and releases the healthy device right away.
- Audio processing moved off the Windows audio thread onto a high-priority
  worker. Microphone and system audio share one clock, drift is corrected
  without clicks, and gaps are written as silence, so playback stays aligned
  with transcript timestamps.
- A microphone that never sends audio is reported as stalled. Paused audio no
  longer leaks into the first moments after **Resume**.
- Transcription warnings now appear in the main window. The warning after a
  slow finish only says audio was kept when it actually was.
- Crashes, including crashes in transcription and document workers, are
  written to the app log as a short report without transcript text.

## Import and Enhance

- Enhance reports a busy or failed start immediately instead of staying on
  "Processing". Jobs keep running when you close the dialog or switch
  meetings, and the result shows the provider and model that actually produced
  the transcript.
- Cloud uploads from Enhance need the same destination approval as Import.
- A cloud failure falls back to your configured local engine. Translation is
  offered only for engines that can translate.
- Hosted Whisper handles long meetings: large recordings are converted to
  compact mono audio and split to fit the OpenAI upload limit. Custom Whisper
  endpoints stream uploads from disk. Text-only responses get real passage
  timing.

## Library

- **Trash**: deleted meetings stay in Trash for 30 days with restore and
  permanent delete. Trashed meetings are read-only and hidden from search,
  Meeting memory, exports and integrations.
- Archive search filters saved text before applying limits and offers
  **Load more**, so older notes are no longer skipped.
- **Encrypted backups**: manual backups can be protected with a passphrase
  (Argon2id and XChaCha20-Poly1305). The passphrase is not stored and cannot
  be recovered.
- Restore can optionally repair missing audio for meetings that already
  exist. It never overwrites local files and skips audio you removed on
  purpose after this version.
- Export transcripts as **SRT** or **WebVTT** subtitles, with optional speaker
  labels, for one meeting or an Archive batch.

## Speaker profiles (opt-in)

- Off by default. When on, you can save a speaker's voice while renaming them;
  later meetings suggest that name, and automatic naming is a separate switch.
- Voice data stays on this PC, is never uploaded, and is not included in
  backups. Turning the feature off deletes all saved voices, including from
  pre-upgrade database copies.
- Matching accuracy has not been measured on real meetings.

## Settings and window

- **Settings → General → Close button**: keep running in the tray (default)
  or quit. A one-time notice explains the tray behavior. Quitting during a
  recording keeps the window open so you can save it.
- **Start ClawScribe when I sign in to Windows** starts the app in the tray so
  call detection runs. Off by default; the uninstaller removes the entry.

## Security and reliability

- The webview can only load individual recording files; the broad app data
  file scope and unused network permissions are removed, along with 18 unused
  commands.
- Microsoft sign-in validates the sign-in response before reporting success
  and no longer shows raw provider errors. A leftover plaintext Microsoft token
  file is deleted after migration.
- FFmpeg runs only from the app's own folder; it is never taken from PATH or
  the working directory or downloaded at runtime.
- Microsoft 365 destination pickers show all pages, and creating a
  destination is not retried after a server error. Ollama downloads no longer
  stay locked after a connection error.
- Preview updates compare prerelease numbers correctly (preview.10 after
  preview.9).

## Compatibility

- Three additive database migrations. A copy of the database is kept before
  migrating. Older builds cannot open the migrated database and offer the
  recovery library instead.
- Backups without trashed meetings remain restorable by 0.68.x. Backups that
  contain trashed meetings, and encrypted backups, need this version or later.
- Crash-recovery files written during capture by this version cannot be read
  by older builds.

## Validation and limitations

Every change was reviewed and re-reviewed; two independent final reviews found
no blockers. The self-hosted runner repeats native validation, frontend tests
and the packaged installer checks for this build.

Not yet tested on real hardware: dual-source capture (microphone and system
audio, including Bluetooth and non-48 kHz devices) with pause, resume, device
unplug and stop; launch at sign-in and uninstall; Hosted Whisper with a long
recording; encrypted backup and restore on a real profile; speaker profile
matching on real voices. Do not treat the preview as stable-ready.

## Install and update

Use the Windows x64 setup executable or MSI. The `windows-gpu` profile uses
Vulkan for Whisper and DirectML for ONNX engines. Detached updater signatures
are separate from Windows Authenticode signing; an unsigned installer may
trigger a Windows warning.

Enable **Include prereleases** in Updates to discover this build, or install it
manually. The release tag is `0.69.0-preview.1`; installer filenames, Windows
and `latest.json` use numeric version `0.69.0`, so it updates 0.68.2-preview.1
in place. Stable-only installations remain on 0.67.0.
