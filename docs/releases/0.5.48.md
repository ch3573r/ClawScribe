# ClawScribe 0.5.48 Preview

This Windows GPU preview updates the optional advanced Codex summary provider
for GPT-6.1 Sol. Local recording and transcription continue to work without
Codex sign-in.

## GPT-6.1 Sol and the bundled runtime

ClawScribe now bundles Codex app-server **0.159.2**, replacing 0.157.0. The
updated catalog includes **GPT-6.1 Sol** (`gpt-6.1-sol`). In **Settings > Summary**,
choose **Advanced: Codex app-server**, then **Check bundled runtime** to refresh
the models and select GPT-6.1 Sol. Existing saved model choices are preserved.
Availability depends on the signed-in account and workspace.

The picker still reads every page of the runtime's `model/list` response. GPT-6.1
Sol also appears in OpenAI's API fallback choices when its model list cannot be
fetched. Codex uses ClawScribe's isolated profile and keyring credential storage.
The app launches its pinned sidecar; the optional Codex voice host is excluded.

The staging script verifies both the package and executable hashes. Runtime
metadata, About attribution, and build metadata identify the same version.
See the [Codex runtime guide](../codex-runtime.md).

## Validation and remaining acceptance

Validation for the runtime update passed 227 frontend tests, 628 required native
app tests with three exclusions, and five helper tests. Typechecking, a production
frontend build, Rust formatting, script syntax, icons, and repository safety
checks passed. Windows GPU preflight ran on the designated local runner.

The actual staged sidecar passed executable integrity, initialization, signed-out
account/logout, and catalog checks in a fresh keyring-only profile. GPT-6.1 Sol
was picker-visible among eight models. Native regressions cover summary output,
chat reconciliation, auth failures, and provider fallback; these use synthetic
inputs and do not establish authenticated GPT-6.1 output quality.

Before stable promotion, verify ChatGPT sign-in, GPT-6.1 summary generation and
meeting chat in the installed app, including useful partial output and one
assistant response per submission. Complete the [real-device acceptance
checklist](../windows-release.md#required-real-device-acceptance), including
microphone plus system audio, playable saved audio, clean Stop, a second
recording, retained meetings, and installed-app update discovery. This preview
does not claim those checks have passed.

## Installation and updates

Installer, runtime, and updater versions are **0.5.48**, newer than stable 0.5.47.
Draft candidates do not appear in the updater. Once published as a preview,
enable **Include prereleases** to discover it or install manually from its
GitHub Release. The stable update channel remains on 0.5.47. The updater uses
the NSIS setup; an MSI is also provided. Finish recording and saving first.

The `windows-gpu` profile uses Whisper Vulkan and ONNX/sherpa DirectML. A supported
GPU driver or official Vulkan runtime remains required. Tauri updater signatures
are separate from Windows Authenticode publisher signing; Windows may display
an unknown-publisher or SmartScreen warning. Verify installer checksums, updater
signatures, manifest identity, and the exact build commit before distribution.
