# ClawScribe 0.5.60 preview

## Calendars and recording

In **Settings → Add-ons → iCalendar**, import a local `.ics` file or subscribe
to an HTTPS or `webcal` feed. Home shows the next five meetings across your
calendars. Choose **Use for next recording** to prefill the title. Open the
iCalendar panel to review individual invitees. Imports stay on the device,
and subscription addresses use protected credential storage. iCalendar works
without a Microsoft account. See the [iCalendar guide](../integrations/icalendar.md).

Call detection can prompt or start recording for Teams, Zoom, Webex and Google
Meet. Enable automatic stop to end the recording ClawScribe started when the
call ends. Existing Teams preferences continue to apply to Teams until you
select another provider. See [call detection](../teams-detection.md).

## Transcription and local assistants

**Settings → Transcription → Test this PC** measures an installed Whisper,
Parakeet or Nemotron model using German and English samples. The results show
the model, backend and elapsed time. With source attribution enabled, Whisper
and multilingual Parakeet can track language separately for the microphone
and system audio.

**Settings → Add-ons → Local assistant access** lets you connect an MCP client
to search saved meetings and read their notes and transcripts. This read-only
connection is off by default. During recording, the Live assistance panel
appears only while live transcript sharing is enabled.

## Updating and testing

The Windows x64 installer and updater version is **0.5.60**. In **Settings →
Preferences → Updates**, enable **Include prereleases**. Enable startup checks
to be notified when ClawScribe opens, or check manually. Finish recording and
saving before installing. The stable channel continues to offer 0.5.58.

Real-device checks remain pending for updating an existing installation,
subscribing to a real calendar, dual-source recording and saved playback,
automatic stop and a second recording, and a two-hour meeting on the target
notebook. Earlier installed acceptance items are listed in the
[0.5.59 preview notes](0.5.59.md).
