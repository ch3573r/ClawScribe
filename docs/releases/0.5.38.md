# ClawScribe 0.5.38

This release adds optional prerelease updates and publishes the recording,
transcription, and meeting-notes improvements from 0.5.37 on the stable channel.

## Updates

- Stable releases remain the default. Turn on **Include prereleases** in
  **Settings > Preferences > Updates** or **About** to receive previews too.
- The selection persists locally across restarts and applies to startup,
  Settings, About, and tray checks. Checking at launch stays a separate choice;
  enabling prereleases never installs an update automatically.
- Checks compare numeric Windows runtime versions. Drafts and incomplete
  uploads are excluded; a newer stable release is also offered to preview users.
  Turning previews off waits for a newer stable build and never downgrades.
- The dialog installs the exact release that was checked. Channel changes
  invalidate stale results, concurrent checks share one request, and failed
  checks can be retried immediately. Network and rate-limit errors are visible.
- Update controls include accessible labels, a prerelease badge, download
  progress, and clear no-update results. Finish recording and saving the current
  meeting before installing. Both channels retain Tauri signature checking.

## Included Recording And Meeting Improvements

The [0.5.37 changes](0.5.37.md) are included: durable recording recovery,
bounded capture queues and import/retranscription buffers, short-utterance
preservation, transcript revision retention, protected provider credentials,
finite summary context budgets, and context selection across entire transcripts.
Long-recording diarization remains memory intensive, and a running Parakeet native
call must finish before another local inference job can start.

## Installation And Update Behavior

Version 0.5.38 is greater than both 0.5.36 stable and 0.5.37 preview. The stable
`latest.json` points to the 0.5.38 NSIS installer, so older installations can
check for this update without opting into previews first. The new opt-in control
becomes available after installing 0.5.38.

The Windows x64 `windows-gpu` build includes Whisper Vulkan and ONNX/sherpa
DirectML paths. A supported GPU driver or the Vulkan runtime is still needed at
startup; successful compilation alone does not establish active acceleration.

Tauri updater signatures and Windows publisher signing are separate. Windows
security policy can still block an installer. Selecting stable or preview
updates does not bypass that policy. Review the published signing status,
checksums, build metadata, and verification record alongside the installers.

## Validation And Remaining Acceptance

The updater changes passed frontend typechecking, 50 frontend tests, a production
frontend build, a native Windows GPU check, all 47 required native regression
tests, and a live GitHub release-feed/manifest compatibility test. The publication
verification record identifies the final installer build and integrity checks.
The updater change does not alter the active audio-driver revision or native
capture pipeline.

Real microphone/system-audio capture, graphical installation/upgrade, native UI
scaling, multilingual accuracy, and sustained i5-1235U / 8 GB performance still
require real-device acceptance. No capture-smoke confirmation is asserted for
this release. Review generated decisions, owners, deadlines, and quantities
against the transcript and audio. Full-repository Rust formatting retains
pre-existing differences in unchanged files.
