# ClawScribe 0.68.0-preview.1

This Windows GPU prerelease replaces MAI-Transcribe with standard Azure Speech
for optional cloud file transcription. It is for manual evaluation and does
not advance the stable update channel.

## Azure Speech

Select **Azure Speech** under **Settings > Transcription** after enabling cloud
transcription. Use the Speech resource endpoint, such as
`https://example.cognitiveservices.azure.com`, and that resource's key. A Foundry
project URL ending in `/api/projects/...` is not a Speech endpoint.

The request uses standard Fast Transcription without enhanced mode or a MAI
model. This addresses the enhanced-mode rejection from resources in regions
such as Germany West Central. Azure selects the standard model automatically;
the model field has been removed from this provider's settings.

Existing provider settings retain their endpoint, region, cloud opt-in, and
protected API key. Legacy MAI model choices resolve to standard Azure Speech.
Live recording continues to use the configured local fallback; cloud
transcription remains opt-in for imports and Enhance.

Language hints use Azure locale codes, including `de-DE` for German. Azure word
timestamps are retained when supplied. Phrase-only or combined-only responses
keep their existing conservative timing fallback. Azure Speech does not offer
English translation here; choose local Whisper for that operation.

## Validation and limitations

Frontend regression tests cover the provider label, saved settings, cloud
opt-in, model selection, and supported language options. Rust regression tests
cover the standard multipart request, locale conversion, short German text,
real word timing, stale translation requests, and preservation of legacy
settings and credentials. The designated self-hosted runner performs native
validation and installer checks before distribution.

A direct standard Speech API probe accepted synthetic silence in Germany West
Central. The installed prerelease has not yet been tested against Azure with
real German speech, short utterances, overlapping speakers, silence, or a long
mixed-source meeting. Real microphone plus system-audio capture, stop and restart,
installed upgrade, and target-notebook performance acceptance are also pending.
Do not treat the preview as stable-ready.

## Install and update

Use the Windows x64 setup executable or MSI. The `windows-gpu` profile uses
Vulkan for Whisper and DirectML for ONNX engines. Detached updater signatures
are separate from Windows Authenticode signing; an unsigned installer may
trigger a Windows warning.

Enable **Include prereleases** in Updates to discover this build, or install it
manually. The source version and artifact names are `0.68.0-preview.1`; Windows
and `latest.json` use numeric version `0.68.0`. Stable-only installations remain
on 0.67.0. A later changed build needs a higher numeric version to update this
preview in place.
